# 相对67.40基线

- 独立新目录，删除新实现中legacy/segformer双路径，仅保留spatial_pyramid。
- 新增4尺度RGB空间先验、门控、深到浅逐级3×3融合；保留两层SpatialAdapter。
- 默认crop392→448、width64→96；提供392/64结构对照配置，共用一套代码。
- 环境固定torch2.7.1/cu128；支持Python3.10–3.12；GPU容量及BF16前后向实测检查。
- AMP调用更新，模型下载每约5秒显示进度，ZIP打印字节数/哈希并保存校验文件。
- 原数据划分、类别映射、优化器、LoRA、增强、30轮、最佳域验证选择和自动续训保持。
- 10篇论文调研后：新增有效邻域边界辅助监督（0.1）与Lovasz（0.2），推理跳过边界头；配置支持两项关闭/单项/联合对照，旧断点不可跨代码恢复。

- 安装时禁用持久pip缓存，避免50GB数据盘因CUDA轮子安装副本和缓存副本同时存在而耗尽空间。
- 不包含旧模型权重、虚拟环境、缓存或历史运行。原4090工程未修改。
