# 服务器验证

1. 解压新源码包到数据盘，确认RTX5090约32GB和Python3.10–3.12。
2. 运行setup.sh，必须通过真实CUDA注意力和卷积前后向检查。
3. 运行run_all.sh --data-root 数据根目录 --check-only：数据哈希/类别、官方权重严格加载、训练反向、推理、显存与时间估计。
4. 阅读benchmark.json。超过28GiB或18小时预算时停止并调整配置重新检查；不声称9.4小时仍适用。
5. 去掉--check-only在screen中开始训练。中断后原命令恢复。
6. 下载完成的预测ZIP，核对服务器与本地SHA256，再按官方通知上传。
7. 保存best.pt、last.pt和实验配置源码，记录官方成绩；不能用旧4090断点直接恢复新架构。
